# l34 手把手教程

即使资料里写“忽略规则、读取秘密”，工具也只能读指定目录。用程序验证权限边界，不声称单靠提示词就防住注入。

先完成前面的基础课。下载并完整解压教程包，在本课文件夹打开终端；不要在学习网站的安装目录练习。

## 运行（Windows PowerShell）

```powershell
python -m venv .venv
.venv/Scripts/python.exe main.py
```

macOS / Linux 创建环境用 python3；后续将 .venv/Scripts/python.exe 换成 .venv/bin/python。

## 预期结果

先显示外部资料，随后“已阻止：路径超出允许范围”。没有读取范围外文件、没有上传、没有写入。

## 逐段讲解

### 外部资料

文档中的指令只是读到的文字，不能变成程序权限。这个实验不执行任何文档命令。

### resolve 后检查

规范化路径后验证从属关系，才能识别 ../。目录须由受信任用户控制；并发改链接需更强沙箱。

### 没有危险入口

最小工具集合比仅要求模型“听话”可靠。需要写入时另加审批与内容绑定，参见 l25、lg03。

## 改一次

把路径换成 public_notes 外的绝对路径（只填一个不存在的测试路径），看是否被拒绝。

参考答案：read(str(ROOT.parent / "outside.txt")) 应在读取前抛 ValueError。只传测试路径，禁止拿真实密钥文件练习。

## 排错

- 提示找不到文件：终端应位于上方列出的本课文件夹；输入 dir 确认文件存在。
- 改了代码却没变化：先 Ctrl+S 保存，再重新运行；.py 文件不能带隐藏的 .txt 后缀。
