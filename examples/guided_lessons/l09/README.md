# l09 手把手教程

用 SQLite 保存两条任务，只完成第一条，再重新连接确认记录存在。SQLite 是一个本地数据库文件，不需安装服务器。

先完成前面的基础课。下载并完整解压教程包，在本课文件夹打开终端；不要在学习网站的安装目录练习。

## 运行（Windows PowerShell）

```powershell
python -m venv .venv
.venv/Scripts/python.exe main.py
```

macOS / Linux 创建环境用 python3；后续将 .venv/Scripts/python.exe 换成 .venv/bin/python。

重复运行不增加重复记录。

## 逐段讲解

### CREATE TABLE

表像一张有列名的表格。id 是唯一编号，title 是文本，done 用 0/1 表示状态。

### 问号占位

SQL 与值分开放，数据库会把参数当数据。不要用字符串拼接把用户输入塞进 SQL。

### UPDATE ... WHERE id

WHERE 限定只改编号 1。with 正常结束时提交；第二个连接读取到提交后的持久记录。 closing 负责关闭连接，内部的 db 上下文负责提交或回滚，这两个动作不同。

## 改一次

把更新条件的 id 改为 2，再运行并查看待学习列表。

参考答案：最后参数由 (1, 1) 改为 (1, 2)。两条 done 都为 1，待学习列表为空；第一条是上次已经保存的状态。

## 排错

- 提示找不到文件：终端应位于上方列出的本课文件夹；输入 dir 确认文件存在。
- 改了代码却没变化：先 Ctrl+S 保存，再重新运行；.py 文件不能带隐藏的 .txt 后缀。
