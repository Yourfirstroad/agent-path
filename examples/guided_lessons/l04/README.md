# l04 手把手教程

把完成比例写成函数：输入完成数和总数，返回比例。它既能被页面使用，也能被下一课的测试使用。

先完成前面的基础课。下载并完整解压教程包，在本课文件夹打开终端；不要在学习网站的安装目录练习。

## 运行（Windows PowerShell）

```powershell
python -m venv .venv
.venv/Scripts/python.exe main.py
```

macOS / Linux 创建环境用 python3；后续将 .venv/Scripts/python.exe 换成 .venv/bin/python。

## 预期结果

2/5 → 40%
0/0 → 0%

数量不合法

## 逐段讲解

### def completion(done, total)

def 定义可反复使用的一组指令。done 和 total 是调用者交进来的参数；类型注解供人和工具阅读，不会自动验证输入。

### return

return 把结果交回调用位置，print 只显示。这里约定总数零时返回 0，避免除以零。

### if __name__ == "__main__"

直接运行文件才执行演示，别的文件 import 它时只获得函数，不自动打印；为测试留出接口。

## 改一次

在列表里加 (1, 4)，不修改函数。

参考答案：列表改成 [(2, 5), (0, 0), (3, 3), (1, 4)]。新增一行 1/4 → 25%；函数逻辑不依赖固定任务列表。

## 排错

- 提示找不到文件：终端应位于上方列出的本课文件夹；输入 dir 确认文件存在。
- 改了代码却没变化：先 Ctrl+S 保存，再重新运行；.py 文件不能带隐藏的 .txt 后缀。
