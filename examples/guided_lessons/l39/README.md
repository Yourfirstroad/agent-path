# l39 手把手教程

给四个作品写一份能被别人复现的说明。提供生成器和一份清晰标记的教学示例，空证据不会被自动填成“已验证”。

先完成前面的基础课。下载并完整解压教程包，在本课文件夹打开终端；不要在学习网站的安装目录练习。

## 运行（Windows PowerShell）

```powershell
python -m venv .venv
.venv/Scripts/python.exe main.py
```

macOS / Linux 创建环境用 python3；后续将 .venv/Scripts/python.exe 换成 .venv/bin/python。

## 预期结果

生成 portfolio-l10/l20/l30/l38.md 四份文件；再次执行只显示保留已有。打开 example.md 对照结构，填写自己的事实。

## 逐段讲解

### exists 保护

已经写过的作品说明不被重新生成覆盖。模板是起点，不是替你编造成果。

### 证据与取舍

证据回答“怎么知道能用”，取舍回答“为什么这样做”。用一条真实失败及修复比堆框架名更有说明力。

### 岗位对照

在资源库打开仍有效的岗位样本，对每项技能标已实做/练习中/未涉及；样本不是市场统计，更不是就业保证。

## 改一次

选 l10，按 example 的结构补齐一次真实演示，然后重新运行生成器确认内容不丢。

参考答案：在 portfolio-l10.md 手工写日期、三条命令实际输出、一个失败输入与修复。运行后应提示“保留已有”，你写的文字仍在。

## 排错

- 提示找不到文件：终端应位于上方列出的本课文件夹；输入 dir 确认文件存在。
- 改了代码却没变化：先 Ctrl+S 保存，再重新运行；.py 文件不能带隐藏的 .txt 后缀。
