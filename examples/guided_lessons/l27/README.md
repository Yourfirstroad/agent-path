# l27 手把手教程

把文本变成一排数字，再比较方向是否接近。先用看得见的三维词频特征学会计算，不把数学示例冒充语义模型。

先完成前面的基础课。下载并完整解压教程包，在本课文件夹打开终端；不要在学习网站的安装目录练习。

## 运行（Windows PowerShell）

```powershell
python -m venv .venv
.venv/Scripts/python.exe main.py
```

macOS / Linux 创建环境用 python3；后续将 .venv/Scripts/python.exe 换成 .venv/bin/python。

## 预期结果

模型是教学词频-v1，维度 3。Python 对 Python 函数的相似度为 1.0；蟒蛇对三条都为 0.0，显示它不懂同义词和多义词。

## 逐段讲解

### FEATURES / embed

每一维分别数 Python、HTTP、数据库出现次数。查询和文档必须用完全相同的映射，否则数字不能直接比较。

### cosine

余弦衡量向量方向。先算点积，再除以两条向量的长度；零向量返回零，不做除零运算。

### 排序与限制

相似度高不代表事实真实，分数并非概率。本课词频可完全解释；真实 embedding 需再选择模型、下载权重或调用服务并记录维度与成本。

## 排错

- 提示找不到文件：终端应位于上方列出的本课文件夹；输入 dir 确认文件存在。
- 改了代码却没变化：先 Ctrl+S 保存，再重新运行；.py 文件不能带隐藏的 .txt 后缀。
