# Agent Path 手把手教程包

每个 lXX 文件夹是独立实验，先打开对应 README.md。Python 建议 3.12，Node.js 使用 >=22.12 的受支持版本。首次安装依赖需要网络；默认练习不调用收费模型。

在 Windows 文件资源管理器进入本课文件夹，地址栏输入 powershell 并回车；在编辑器打开同一文件夹。只把命令放进终端，把代码保存在标明的文件中。用记事本时选择 UTF-8、保存类型“所有文件”，检查没有 .py.txt。完整解压再运行，不能在 ZIP 预览里运行。

Windows 命令使用 .venv/Scripts/python.exe，无需激活环境。macOS / Linux 创建环境用 python3 -m venv .venv，后续改用 .venv/bin/python。网站阅读可用手机，Python / React / Docker 实操需要电脑；不要求你在手机安装开发工具。

LangChain / LangGraph 的九个实验在另一个 agent-labs.zip 中，课程页同时提供下载和逐段讲解。各课数据库只用于自己的实验，不要放入网站数据或私人学习备份。

所有讲义中的预期输出是对照标准，不是你的学习记录；真实模型质量、生产权限与部署仍需另行验收。代码用于学习，未经生产安全审计。官方来源与核对日期在网站每课底部。
