# l40 手把手教程

建立一份真实的依赖清单与迁移记录。示例只采集本环境实际版本，官方新版本和兼容性由你阅读、试验后填写，绝不自动宣称最新版。

先完成前面的基础课。下载并完整解压教程包，在本课文件夹打开终端；不要在学习网站的安装目录练习。

## 运行（Windows PowerShell）

```powershell
python -m venv .venv
.venv/Scripts/python.exe main.py
```

macOS / Linux 创建环境用 python3；后续将 .venv/Scripts/python.exe 换成 .venv/bin/python。

## 预期结果

生成 dependency-review.json，显示当前 Python 版本及已安装包。独立空环境里三个包可能都显示未安装，这是实际情况；online_checked=false，不表示已核对最新版本。

## 逐段讲解

### metadata.version

读取正在运行的 Python 环境已安装版本，不联网，也不升级任何东西。

### official_sources

更新入口是官方文档/发布记录。查看变化是否影响自己用到的接口，再选择候选版本。

### 隔离比较

复制某课到新的实验目录，创建新 .venv 测试候选版本，保留原环境与相同测试。通过后再决定是否迁移。

## 改一次

选一条官方变更，按 review-template.md 写一次“可能影响/不影响”的分析；没跑迁移时保留未验证。

参考答案：例如仅文档措辞变化可写“不涉及当前代码，暂不升级”；若 model_validate 行为改变，应在两套隔离环境跑 l18 相同输入，保存输出后再决定。不要为了让报告看起来完整编造版本或测试。

## 排错

- 提示找不到文件：终端应位于上方列出的本课文件夹；输入 dir 确认文件存在。
- 改了代码却没变化：先 Ctrl+S 保存，再重新运行；.py 文件不能带隐藏的 .txt 后缀。
