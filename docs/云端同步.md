# 学习进度与每日提醒同步

## 已确定的目标

用户于 2026-10-28 要求手机和其他电脑自动同步学习进度，并允许增加免费云端账号。前端继续使用 GitHub Pages；云端选用 Supabase Free。沿用本站的三套配色和课程稳定 ID，不迁移或重置原有记录。

同步课程验收、自测、项目验收、每日时长。笔记与资料收藏保留在当前浏览器，既不上传到数据库，也不提供给每日提醒读取。未登录时保持原有使用方式；登录后的缓存按用户 ID 分开，不自动把访客记录覆盖到账号。用户可在设置页明确选择导入原有进度。

## 实现与权限

- `cloud/001_progress_sync.sql`：账号隔离、校验、版本冲突保护、恢复前进度快照、只读提醒连接。只在专用 Supabase 项目中执行。
- `cloud/002_curriculum.sql`：48 节课程 ID / 顺序 / 自测键及 4 个项目 ID，只有公开资料；更新课程时同步维护。
- `cloud-client.ts`：登录会话、进度请求和只读连接。请求绑定当次账号的访问令牌，避免另一个标签切换账号造成串写。
- `browser-storage.ts`：按账号分开的本机缓存和私有笔记；联网确认后更新进度，保留原有备份格式。
- `cloud-settings.tsx`：学习账号登录 / 注册、进度迁移、退出设备、提醒连接生成与撤销。

服务端写入只允许当前认证账号，不接受调用者指定其他人的所有者 ID。读取表启用 RLS；禁止客户端直接修改表，只开放经过检查的函数。每次写入检查 revision，旧设备写入会被拒绝并刷新，不能静默覆盖另一台设备的修改。进入页面、回到窗口、恢复联网或可见页面每 30 秒读取最新进度。

离线时显示该设备缓存，进度修改需要联网确认，笔记仍可本机保存。不会把断网、缺少提醒连接或权限撤销误报为零进度。已完成状态由三项验收与正确答案共同计算，不按日期自动完成。

## 一次性云端准备

1. 用户在 https://supabase.com/dashboard/sign-in 完成注册 / 登录和服务条款确认。
2. 创建专用的 Free 项目。数据库密码由用户自己输入，不发送到聊天；不要选择付费组织或升级套餐。
3. 在 SQL Editor 依次执行两个 SQL 文件。把 Auth Site URL 及允许的重定向配置为 `https://yourfirstroad.github.io/agent-path/`。
4. 只把项目 URL 和 **Publishable key** 配置到未跟踪的 `.env.local`：

```dotenv
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_YOUR_PUBLIC_KEY
```

Publishable key 是浏览器公开标识，权限由登录和 RLS 决定。不能把 secret / service_role / 管理员令牌放进前端或仓库。

5. 构建、验证并发布后，用户在网站“学习设置 → 跨设备学习进度”创建或登录自己的学习账号；这与 Supabase 管理账号是不同用途。启用邮箱验证，不关闭验证来绕过投递问题。

Supabase Free 官方定价核对日期为 2026-10-28：免费额度包括 500 MB 数据库、50,000 月活跃用户；最多 2 个活跃免费项目，连续一周无活动可能暂停。仅使用免费方案，不购买套餐。默认邮件服务主要用于项目团队邮箱，且有发送限制；面向更多访客开放注册前需另行配置合适的邮件服务，不能声称所有外部邮箱的验证投递已经通过。

来源：[免费方案](https://supabase.com/pricing)、[邮件服务限制](https://supabase.com/docs/guides/auth/auth-smtp)、[RLS](https://supabase.com/docs/guides/database/postgres/row-level-security)。

## 连接每日提醒

用户在网站中明确生成“提醒连接文件”。文件包含一个仅能读取进度摘要的随机凭证，不是密码，不能写入进度，也不能读取笔记。数据库只保存凭证的 SHA-256 摘要；重新生成或点击撤销会使旧凭证失效。

在本机私有目录保存为 `work/reminders/connection.json`，勿提交或公开分享。每日任务调用：

```powershell
.venv/Scripts/python.exe scripts/read_cloud_progress.py --connection work/reminders/connection.json
```

请求固定指向已连接项目的 `ap_read_reminder_progress` 只读函数。输出只允许：有无同步记录、完成数量、下一课 / 最后活动课程、验收情况、学习时长、更新日期。缺少连接、服务暂停或连接撤销均明确报错，不回退为零进度。

只有真实连接验证成功后才修改使用者现有的每日任务，保留每天 09:00 北京时间及原聊天；任务提示不放凭证。提醒只读取，不完成验收、不上传学习记录、不自动公开发布。

提醒读取器有 4 项 Python 单元测试，验证只读请求、缺失连接、撤销错误和意外私有字段保护。真实账号连接完成前，不宣称云端同步或每日提醒已经上线。
