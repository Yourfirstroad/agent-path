## 2026-10-29 · Harness 与 Deep Agents

补充 14 节进阶教程，总计 62 课、10 阶段、36 项资料。先手写 Harness，再使用实际 Deep Agents SDK，最后进入原有部署与作品集阶段。新课程稳定 ID 为 h01–h06、da01–da08。每课具备完整文件、环境/运行命令、预期结果、逐段讲解、修改练习参考答案、排错、三项完成标准及自测。

专业性以可复现证据和边界为准，不把框架热度当作就业统计。当前内容选择依据：Deep Agents 官方定位为基于 LangChain / LangGraph 的 Agent Harness；课程覆盖其实际文件、规划、记忆、Skills、委派、审批与上下文能力。手写 Harness 用于理解这些能力的责任边界，不能当作生产沙箱。

核对并实测版本：Python 3.12.15、Deep Agents 0.7.32、LangChain 1.4.7、LangGraph 1.2.18、langgraph-checkpoint-sqlite 3.1.2。锁文件位于 examples/harness_labs/requirements-lock.txt。当前接口显式添加 TodoListMiddleware，StateBackend 无旧 runtime 参数，StoreBackend 显式提供 namespace 工厂。
