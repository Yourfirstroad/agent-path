# 技术方案

## 架构

React 负责展示和交互；FastAPI 提供课程内容与状态接口；SQLite 保存状态。生产构建由同一个 Python 服务提供，避免用户同时启动两个服务。

- backend/curriculum.py：稳定 ID 的课程、项目和资料数据。
- backend/app.py：输入校验、SQLite 事务、快照备份、静态资源。
- src/features/learning/store.tsx：请求、保存状态、错误与通知。
- src/features/learning/pages.tsx：六类工作台页面和课程详情。
- src/styles/learning.css：finesse 深色视觉和移动适配。
- src/features/learning/theme.tsx：三套完整主题、浏览器偏好保存及跨标签同步，独立于学习数据库；存储受限时保留本次显示并明确提示。浅色时通知框同步使用浅色。

## 接口

GET /api/health、/api/bootstrap、/api/export。
PATCH /api/lessons/{id}；PUT /api/projects/{id}、/api/bookmarks/{id}、/api/settings。
POST /api/import：严格校验、先快照、事务替换。未知 ID、非法时长、过长笔记、格式错误都拒绝。
SQLite 连接显式关闭，避免 Windows 文件锁泄漏。

## 持久化

state 表以 kind/id 为主键，value 为经过校验的 JSON。课程完成状态由服务端根据三项验收与自测答案计算。导入不允许伪造不满足条件的完成状态。备份版本 1，恢复前快照与导出格式一致。

## 安全边界

只监听本机，限制 Host 和写入 Origin，资源路径不能逃出 dist，备份体积上限 2 MB。课程不保存 API key。无认证，不适合直接暴露到公网。当前未做独立渗透审计。

## 更新策略

按官方文档与维护仓库核查，区分版本迁移、稳定基础、可选进阶和已弃用方案。保留课程 ID，不重置用户状态。依赖升级先跑构建和针对性回归；不要因“最新”盲目升级全部库。
